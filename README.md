# quicksearch-windows — мгновенный поиск файлов ⚡

Мгновенный поиск файлов на Windows. Индексация дисков занимает секунды, результаты появляются по мере ввода текста.

## Возможности

- 🔍 Поиск по именам файлов и папок за миллисекунды
- 📁 Поддержка локальных дисков, сетевых шар и USB-накопителей
- ⌨️ Горячие клавиши для быстрого запуска поиска
- 🔄 Автоматическое обновление индекса при изменении файлов
- 🪶 Минимальное потребление памяти (~10 МБ)

## Установка

1. Скачайте установщик из раздела [Releases](../../releases)
2. Запустите `EverythingSetup.exe` и следуйте инструкциям мастера установки
3. Готово — программа стартует вместе с Windows (можно отключить в настройках)
